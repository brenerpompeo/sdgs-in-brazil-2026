# SDGs in Brazil 2026

Landing Page Oficial do Evento **SDGs in Brazil 2026**, organizado pelo **Pacto Global da ONU - Rede Brasil**, realizado na Sede das Nações Unidas em Nova York no dia 18 de Setembro de 2026.

## 🚀 Tecnologias
- React 19 + TypeScript + Vite
- Tailwind CSS v3
- Lucide Icons
- Exportação de eventos para calendário (.ics)
